Tuesday, January 21, 2025

Data News #2025 - 1
Nasdaq to Introduce the Market Data Knowledge Center, Now available on Nasdaq Data Link

Products Impacted:

  • All Nasdaq Proprietary Data Products
  • NFN Secure Web Service
  • NFN Data Service

Contact Information:

  • Investment Intelligence
  • NFN Operations at + 1 301 978 5307 (Option #6)

What you need to know:

Please note, all Nasdaq Data Product information stored on nasdaqtrader.com is now available on Nasdaq Data Link through the new Market Data Knowledge Center here.

Nasdaq Trader data pages will be redirected to their corresponding Nasdaq Data Link page to allow for a seamless user experience on Tuesday, February 18th, 2025. This includes Nasdaq Fund Network registration and product information as well as data specifications currently available on nasdaqtrader.com/NFN.

What is changing?

The Market Data Knowledge Center has been added to Nasdaq Data Link to evolve the customer support experience. The following pages have been included:

Market Data Specifications - page provides information pertaining to each product’s data delivery options.

  • Previously found on Nasdaq Trader here.
  • Can now be found here.

    • Nasdaq North America Market Pricing - All pricing information pertaining to North American Market data products.

  • Previously found on Nasdaq Trader via this URL: https://www.nasdaqtrader.com/Trader.aspx?id=DPPriceListAll
  • Can now be found here.

    Nasdaq European Data Pricing and Policies - All pricing and policy related material for European Markets.

  • Remains available on Nasdaq.com here.

    • Agreements/Forms, Policies, Usage Reporting – All data product agreements, forms, policies, and usage reporting can be found here.

  • Previously found on Nasdaq Trader here.
  • Can now be found here.

    Network Support Information - This page seeks to provide customers with all necessary network information for data delivery- UDP/IP information, bandwidth report, monthly peak message rate statistics, direct connectivity providers, and extranet providers.

  • Previously found on Nasdaq Trader here.
  • Can now be found here.

    Nasdaq Global Data Products - This page seeks to highlight our data products as a whole and provide users with information pertaining to communication.

  • Previously found on Nasdaq Trader here.
  • Can now be found here.

    Nasdaq Fund Network - NFN customers are encouraged to bookmark this new website for access to information pertaining to the Nasdaq Fund Network going forward.

  • Previously found on Nasdaq Trader here.
  • Can now be found here.

  • For additional information, Contact Nasdaq Fund Network Operations at +1 301 978 5307 (Option #6).

    When is this effective?

    On Tuesday, February 18th, 2025 the Nasdaq Trader data pages mentioned above will be redirected to their corresponding Nasdaq Data Link page.
